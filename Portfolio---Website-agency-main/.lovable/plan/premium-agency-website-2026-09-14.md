# Premium agency website

## Build

- Create a distinctive premium visual system with strong editorial typography, warm neutral surfaces, and a vivid coral accent.
- The website should feel **futuristic, visually striking, sophisticated, and highly polished**, while remaining professional and easy to navigate.
- Design the website itself as a **showcase of our web design and development skills**—it should immediately demonstrate to potential clients that we can create modern, futuristic, visually pleasing websites tailored to their business and brand.
- Use creative layouts, sophisticated visual hierarchy, subtle gradients, glassmorphism where appropriate, refined micro-interactions, smooth transitions, and restrained motion to create a memorable experience without making the website feel cluttered.
- Prioritize **visual impact, originality, usability, responsiveness, and premium aesthetics** so that a potential client visiting the website thinks, *"I want a website like this for my business."*
- Add a shared responsive navigation and footer.
- Build dedicated Home, Services, Portfolio, About, Pricing, Testimonials, and Contact pages.
- Use generated portfolio imagery and restrained motion.
- Make contact and package-selection interactions clear and usable.

## Quality checks

- Add unique search and social metadata to every page.
- Verify desktop and mobile layouts, navigation, animations, interactions, and form states.
- Ensure excellent responsiveness across mobile, tablet, and desktop.
- Ensure accessibility, readable typography, appropriate contrast, fast loading, and clean visual hierarchy.
- Make sure animations enhance the experience rather than distract from the content.
- Ensure the overall result feels like a **high-end futuristic digital agency**, not a generic AI-generated template.
